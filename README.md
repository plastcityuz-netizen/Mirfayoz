# BALANS AI

`npm start` — Python 3 orqali statik saytni `http://localhost:4173` da ochadi; paket o‘rnatish shart emas.
`#/` — UZ/RU marketing sayti, ikki tema, tariflar, savol-javob va demo formalar.
`#/demo` — namunaviy boshqaruv paneli, rollar, modullar, AI CFO va Ctrl/Cmd+K qidiruvi.
`data.js` → `CONFIG`: `BRAND` nomi, `PRICING` narxlari, `CONTACT` manzillari va `FEATURE_FLAGS` sozlamalari.
Haqiqiy API ulashda `data.js` dagi `dataService` implementatsiyasini almashtiring; ruxsatlarni serverda tekshiring.
Demo ro‘yxatdan o‘tkazmaydi, xabar yubormaydi va to‘lov olmaydi. Chat javoblari namunaviy ssenariylardan olinadi.
`npm test` — demo hisoblari, tarjima kalitlari va rol cheklovlarini tekshiradi.
